# BrowserEngineKit

Medium article: [BrowserEngineKit: The Framework Apple Built for Browsers It Doesn't Want You
Building](https://hari51215.medium.com/browserenginekit-the-framework-apple-built-for-browsers-it-doesnt-want-you-building-fa267e79961f)

No sample app for this topic: BrowserEngineKit's actual functionality (browser extensions, process isolation, JIT compilation) requires an Apple-granted entitlement restricted to approved alternative-browser-engine vendors, so it isn't something a personal developer account can build and run. See the article for the full deep dive.
