# Audio Toolbox

Medium article: [Audio Toolbox: What's Still Worth Learning in Apple's Oldest Audio Framework](https://hari51215.medium.com/audio-toolbox-whats-still-worth-learning-in-apple-s-oldest-audio-framework-ba22060c14c1)

Sample app: [`PixelJingle/`](./PixelJingle) — a tiny retro-arcade app demonstrating Audio
Services (short sound-effect playback via `AudioServicesPlaySystemSound` and system vibration)
and Music Player Services (a hand-built `MusicSequence` played through `MusicPlayer`). See
[`PixelJingle/README.md`](./PixelJingle/README.md) for setup and testing instructions.
