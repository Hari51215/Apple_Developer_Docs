# AVFoundation

Medium article: [AVFoundation in SwiftUI — Capturing, Playing Back, and Exporting Video](https://hari51215.medium.com/avfoundation-in-swiftui-capturing-playing-back-and-exporting-video-5fbdef3e7f31)

Sample app: [`SceneMix/`](./SceneMix) — a record-narrate-export app that captures a video clip
with `AVCaptureSession`, plays it back with `AVPlayer`, records a voice-over with
`AVAudioRecorder`, then mixes both into one file with `AVMutableComposition` and
`AVAssetExportSession`. See [`SceneMix/README.md`](./SceneMix/README.md) for setup and testing
instructions.
