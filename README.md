# Apple Developer Docs — Learning Log

A personal journey through [Apple's Developer Documentation](https://developer.apple.com/documentation),
one framework at a time, in alphabetical order. Each topic gets a companion article on Medium,
and — when it genuinely helps explain the concept — a small SwiftUI sample app.

📝 Articles: [hari51215.medium.com](https://hari51215.medium.com/)

## How this repo is organized

Each top-level folder is one topic/framework, e.g. [`AppClips/`](./AppClips),
[`AlarmKit/`](./AlarmKit). Inside a topic folder:

- `README.md` — the Medium article title + link
- A sample app subfolder (only if one was built for that topic), with its own detailed README
  covering setup, how to run it, and what it demonstrates

Not every topic has a sample app — some frameworks are better explained through the article
alone.
