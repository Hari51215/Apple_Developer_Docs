# BrowserKit

Medium article: [BrowserKit: Apple's Quiet Framework for Moving Bookmarks Between
Rivals](https://hari51215.medium.com/browserkit-apples-quiet-framework-for-moving-bookmarks-between-rivals-0aaed9c3103c)

Sample app: [`Wayfarer/`](./Wayfarer) — an iOS app demonstrating BrowserKit's device-eligibility
check and the full browsing-data export/import flow against mock bookmarks, history, reading
list items, and extensions. See [`Wayfarer/README.md`](./Wayfarer/README.md) for setup and
testing instructions, including an important caveat about what can and can't be verified without
Apple's default-browser entitlement.
