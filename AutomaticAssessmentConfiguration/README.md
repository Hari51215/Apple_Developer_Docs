# Automatic Assessment Configuration

Medium article: [*Automatic Assessment Configuration: What It Takes to Lock macOS Into Exam
Mode*](https://hari51215.medium.com/automatic-assessment-configuration-what-it-takes-to-lock-macos-into-exam-mode-c8203be96514)

No sample app for this topic — the framework only does anything real once Apple grants the
`com.apple.developer.automatic-assessment-configuration` entitlement (requested via Apple's own
form), and its effects only show up in a genuine locked-down exam environment, not a throwaway
sample project.
