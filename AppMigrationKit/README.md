# AppMigrationKit

Medium article: [Apple Just Built a Framework to Help You Leave iPhone. Here's What's Actually In It.](https://hari51215.medium.com/apple-just-built-a-framework-to-help-you-leave-iphone-heres-what-s-actually-in-it-9ea2505cdb76)

No sample app for this topic — AppMigrationKit only does anything inside a real cross-platform
migration flow (an app-extension target, an iOS 26.1 beta environment, and an actual Android
counterpart on the other end), so there's no meaningful demo surface to build solo.
