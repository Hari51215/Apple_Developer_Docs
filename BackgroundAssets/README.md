# Background Assets

Medium article: [Background Assets: Apple's Answer to the Slow First Launch](https://hari51215.medium.com/background-assets-apples-answer-to-the-slow-first-launch-be3f8a38239e)

No sample app for this topic — a real demo would need either App Store Connect hosting for a
Managed asset pack or a full self-hosted manifest server plus App Groups and an extension
target for the Unmanaged path, neither of which fits a throwaway sample project. The article
covers both paths, and the CLI workflow (`ba-package`, `ba-serve`) actually run and tested
locally, through the article text and inline code instead.
