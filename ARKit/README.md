# ARKit

Medium article: [*"ARKit, Explained: How Apple's AR Framework Works — and a Plane-Detection App

Sample app: [`ARDrop/`](./ARDrop) — a tap-to-place demo: point the camera at a flat surface,
tap the detected plane to drop a cube, and reset to clear the scene. See
