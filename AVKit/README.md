# AVKit

Medium article: [Touring AVKit: Apple's Native Video Controls Across iOS, tvOS, macOS, and
visionOS](https://hari51215.medium.com/avkit-apples-native-video-controls-across-ios-tvos-macos-and-visionos-98c138229e13)

No sample app for this topic — AVKit is a thin UI layer over AVFoundation
(`AVPlayerViewController`, Picture in Picture, routing), and the concepts are best explained
through the article and its inline code snippets rather than a standalone demo project.
