# CallKit

Medium article: ["Letting iOS Handle Your App's Calls with CallKit"](https://hari51215.medium.com/letting-ios-handle-your-apps-calls-with-callkit-920ca1cd3e4d)

Sample app: [`CallBench/`](./CallBench) — a fully local CallKit sample that simulates incoming
and outgoing calls, drives mute/hold/end from both the system's native call screen and its own
in-app UI, and uses a synthesized tone to prove out CallKit's audio-session handoff. See
[`CallBench/README.md`](./CallBench/README.md) for setup and testing instructions.
